## Question Types in Each File

- **Theory** — explain the concept, internals, why it works the way it does
- **Tricky** — predict the output, spot the bug, explain the surprising behavior
- **Scenario** — "In your project, how would you handle…" — tests real-world judgment

---

## How to Use This Guide

1. Go topic by topic — do not skip.
2. For each question: try to answer it yourself before reading the answer.
3. Pay attention to **Follow-up questions** — interviewers always dig deeper.
4. Run the code examples locally to reinforce understanding.
